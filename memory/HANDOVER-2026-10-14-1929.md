  - **Context**: redesign request "cleaner, less cheap" + "the theme should still stay the same".

- **Decision**: Fix label overflow with tldraw geo `scale` prop (text only), not truncation.
  - **Context**: tabs read "Das / hbo".
  - **Rationale**: truncation would also change what `readBoardScreens` sends to the agent. `scale` shrinks only text; w/h stay. Must also zero `growY` (tldraw stretched boxes when labels wrapped).
- **Decision**: Old boards heal on open (`fitBoardLabels` in onMount) instead of a one-off script.
  - **Rationale**: works for every board and every user, idempotent, no DB access needed.
- **Decision**: Leave backdrop blur as is.
  - **Rationale**: measured frame times identical with blur on/off (headless browser ~30fps cap). Revisit only if lag reported.
- **Decision**: Keep a few hex values in `TldrawApp.tsx` palette override.
  - **Rationale**: tldraw palette is JS and needs raw hex; comment points to globals.css tokens.

## Pitfalls & Gotchas
- Pushes do NOT auto-deploy. Deploy with `npx vercel --prod --yes` in the main folder; check `npx vercel ls --prod`. Only deploy when papi says "deploy".
- Workflow: edit in worktree branch `claude/canvas-redesign`, commit, then `git -C <main folder> merge --ff-only claude/canvas-redesign`. Dev server runs from the main folder. Writes to the main folder from the worktree session are blocked by a hook.
- Commit messages via temp file (`$TEMP/msg.txt`) to avoid quoting issues.
- Playwright browser can silently be on `/room/demo`; ALWAYS check `location.pathname` before mutating the canvas (once created test frames in demo by mistake; deleted).
- `window.editor` may take a few seconds to appear; poll for it.
- tldraw geo `scale`: rendered box = w/h (do not divide by scale); label size scales. Letter width estimate ~13px, side padding 32px.
- `git revert -q` is not a valid flag; use `git revert --no-edit HEAD`.
- Contrast scripts misread `oklab()` colors (false positives); compute by hand.
- Next.js config changes need a dev-server restart (TaskStop + `npm run dev` in background).
- Python heredoc edits: `\s` in normal strings warns; regex escaping got mangled once.
